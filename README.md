# 소은의 아카이브 다이어리 ♬

## 1. 목적

좋아하는 미디어 콘텐츠를 잊지 않고 기억하고, 홈페이지에 놀러 온 방문자들과 취향을 공유하기 위해 만든 블로그형 개인 홈페이지입니다. 보고 들은 작품마다 별점, 태그, 짧은 감상을 남겼습니다.

- **방문자**: 친구, 콘텐츠를 좋아하는 사람
- **방문자가 할 수 있는 일**: 기록 구경하기, 음악 바로 듣기, OTT로 바로 이동하기, 취향 궁합 테스트, 방명록·작품 추천 남기기
- **메시지**: 콘텐츠를 그냥 소비하는 데서 그치지 않고, 나만의 시선으로 기록하고 공유하는 "콘텐츠 아카이버"로 기억되는 것을 목표로 합니다.
- **내용**: 다양한 콘텐츠 감상과 영감 기록
- **완료 목표**: 일일 방문자 수 100명, 그리고 꾸준한 업데이트로 방문자가 다시 찾아오는 홈페이지로 운영하는 것입니다.

## 2. 주소

- 홈페이지: https://soeun1223.github.io/
- GitHub 저장소: https://github.com/Soeun1223/soeun1223.github.io

## 3. 실행·수정 방법

### 실행하기

별도 설치 없이 https://soeun1223.github.io/ 에 접속하면 바로 사용할 수 있습니다. PC와 휴대폰 모두 지원합니다.

### 수정하기

1. GitHub 저장소에서 고칠 파일(주로 `posts.json`)을 열고 연필 아이콘(Edit)을 눌러 수정합니다.
2. **Commit changes**를 누르면 1~2분 뒤 홈페이지에 반영됩니다.

### (선택) 내 컴퓨터에서 미리 보기

저장소를 내려받은 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:8000`을 열면, 올리기 전에 화면을 미리 확인할 수 있습니다. `index.html`이 `posts.json`을 불러오기 때문에 파일을 더블클릭해서 열면 기록이 보이지 않습니다. (미리 보기로 열어도 방문자 수가 1 올라갑니다.)

```bash
python3 -m http.server 8000
```

### 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 전체 (디자인, 탭, 홈 리포트, 궁합 테스트, 방명록) |
| `posts.json` | 기록 데이터. 글을 추가·수정할 때는 이 파일만 고치면 됩니다 |
| `*.jpg`, `*.webp` | 포스터·앨범 커버 이미지 |
| `supabase/guestbook.sql` | 방명록·작품 추천 저장 테이블 설정 |
| `supabase/visits.sql` | 방문자 수 저장 설정 |
| `.github/workflows/supabase-keepalive.yml` | 무료 Supabase가 멈추지 않도록 3일마다 한 번 깨우는 자동 작업 |

### 기록 추가하기

1. 포스터 이미지를 저장소 최상위에 올립니다. (예: `exit.webp`)
2. `posts.json`에 아래 형식으로 기록을 하나 추가합니다. `id`는 다른 기록과 겹치지 않는 숫자로 정합니다.

   ```json
   {
     "id": 140,
     "category": "영화",
     "title": "엑시트",
     "rating": 4,
     "cover": "./exit.webp",
     "body": "짧은 감상",
     "tags": ["액션", "코미디"],
     "date": "2026. 10. 03",
     "ott": [{ "name": "넷플릭스", "url": "https://www.netflix.com/title/81336395" }]
   }
   ```

   - `category`는 `드라마`, `애니메이션`, `영화`, `음악`, `위시리스트` 중 하나입니다.
   - 음악은 `ott` 대신 `"youtube": "https://www.youtube.com/watch?v=..."`를 넣으면 듣기 버튼이 생깁니다.
   - 위시리스트는 `"subCategory": "드라마"`처럼 원래 분류를 함께 적고, `rating`은 넣지 않습니다.
   - `ott`가 없으면 카드에 "아직 OTT에 공개되지 않았어요"가 표시됩니다.
   - 홈의 기록 수, 비율, 태그 TOP 5, 평균 별점은 `posts.json`을 바탕으로 자동으로 다시 계산됩니다.

3. **Commit changes**로 저장하면(또는 내 컴퓨터에서 고쳤다면 push하면) 1~2분 뒤 홈페이지에 반영됩니다.

### 방명록 글 지우기

Supabase 대시보드 → Table Editor → `guestbook`에서 지울 줄을 선택해 삭제합니다. 추천 글을 지우면 위시 탭에서도 사라집니다.

### 동료 의견과 수정 결과

방문자수, 방명록 기능이 정상적으로 작동하지 않거나 서버에 저장되지 않던 문제를 피드백을 통해 개선했습니다. 이 외에도 추가적인 의견 및 피드백이 있으시면 방명록에 편히 남겨주세요. 

### 스스로 점검하고 고친 것

- 궁합 테스트 점수가 대부분 높게 나오던 문제 → 별점대별로 고르게 출제하도록 바꿈
- 화면 폭 800px 안팎에서 글자가 세로로 쌓이고 가로 스크롤이 생기던 문제 → 960px 이하에서는 휴대폰 배치로 바꿈
- 키보드 초점이 잘 보이지 않던 문제 → 초점선을 두껍게 표시
- 휴대폰에서 짧은 카드 아래에 빈 공간이 크게 남던 문제 → 카드 영역 높이를 지금 보이는 카드에 맞춤

### 사용한 자료

- 글꼴: Pretendard

- 방명록·방문자 수 저장: Supabase 무료 플랜

### AI 도움

제가 낸 아이디어를 AI의 도움을 받아 기능으로 구현했습니다. Y2K·미니홈피 감성의 디자인, 카테고리별로 나눠 보는 탭 구성, 작품 선정과 평가, 플레이리스트 제작 등 "내용" 자체는 제가 직접 고안했습니다.

- **Gemini**
  - 아카이브 웹페이지의 구조(HTML), 레트로 다이어리 스타일의 반응형 디자인(CSS), 동작(JavaScript) 전체 코드를 한 파일로 설계·구현
  - 첫 버전의 게시물 열람·등록·삭제 기능 구현 (이후 게시물은 `posts.json`으로 관리하도록 바꿈)
  - 디자인 디테일 개선
- **Claude Code**
  - YouTube·OTT 링크 찾기와 연결, 플레이리스트 등록
  - Supabase 방명록·작품 추천·방문자 수 기능과 보안 설정
  - 홈 취향 리포트, 취향 궁합 테스트, 정렬 기능 구현
  - 휴대폰 화면 정리, 접근성(초점 표시, 대체텍스트) 보완, 전체 기능 점검
- 모든 작품은 과거 일기 기록과 왓챠피디아 기록을 바탕으로 제가 직접 선정했습니다.

## 5. 만들면서 신경 쓴 점

### 다이어리를 펼친 듯한 콘셉트

화면 전체를 바인더 다이어리처럼 꾸몄습니다. 스프링 링, 오른쪽 인덱스 탭, 왼쪽 프로필 속지로 다이어리를 펼친 느낌을 내고, TODAY/TOTAL 방문자 수와 방명록으로 싸이월드 미니홈피 감성을 더했습니다. 휴대폰에서는 화면 비율 때문에 PC만큼 디자인 콘셉트가 드러나지는 않지만, 모든 기능이 오류 없이 작동하도록 구성했습니다.

### 보여 주기만 하는 게 아니라, 같이 나누는 취향

제 기록을 단순히 전시하는 데서 끝나지 않고, 방문자도 참여하며 재미를 느낄 수 있는 기능을 추가했습니다.

- **취향 궁합 테스트**: 제 기록에 "좋아 / 별로 / 안 봤어"를 고르면 저와 취향이 얼마나 같은지 알려 줍니다. 문제는 제 기록의 별점대별로 고르게 출제됩니다.
- **추천해주세요**: 방문자가 작품을 추천하면 제 위시리스트에 바로 추가됩니다.

### 읽다가 바로 보고 듣기

기록을 읽다가 궁금해지면 바로 이어서 즐길 수 있도록 링크를 추가했습니다. 음악 카드에는 YouTube 듣기 버튼을 달고, 음악 탭 상단에는 YouTube와 Apple Music 플레이리스트를 넣었습니다. 특히 음악은 다른 사람에게 자신 있게 소개할 수 있도록 공들여 고른 곡들 위주로 담았고, 플레이리스트의 곡 순서도 고민해서 정했습니다. (YouTube 플레이리스트는 뮤직비디오 위주라서, 음악 외의 소리가 거슬리지 않도록 순서를 따로 다시 구성했습니다.)드라마·애니·영화 카드에는 해당 작품을 볼 수 있는 OTT 공식 페이지로 가는 버튼을 넣고, 아직 OTT에 공개되지 않은 작품은 별도의 표시를 기재했습니다.

### 기록만 추가하면 알아서 바뀌는 구조

기록은 모두 `posts.json` 한 파일에 모았습니다. 글을 추가하면 탭, 정렬, 홈의 취향 리포트(기록 수, 카테고리 비율, 자주 쓴 태그, 평균 별점), 궁합 테스트 문제가 모두 자동으로 바뀌도록 설계했습니다.

### 실제로 작동하는 실시간 기능

방명록과 방문자 수가 모든 방문자에게 똑같이 보이도록 Supabase 무료 플랜에 연결했습니다. 방문자가 다른 사람의 글을 고치거나 지우거나 방문자 수를 조작할 수는 없도록 막았습니다. 무료 Supabase는 일주일 동안 사용하지 않으면 멈추기 때문에, GitHub Actions로 3일마다 한 번씩 깨우도록 설정했습니다.

### 누구나 편하게 볼 수 있도록

PC와 휴대폰 모두에서 편하게 볼 수 있도록 만들었습니다. 휴대폰에서는 카드를 옆으로 넘겨 볼 수 있고, 지금 보는 카드에 맞춰 높이가 바뀝니다. 화면 폭 320px부터 PC까지 가로로 넘치는 곳이 없는지 확인했습니다. 키보드로 이동할 때 초점선이 잘 보이도록 하고, 모든 이미지에 대체텍스트를 넣었습니다.
